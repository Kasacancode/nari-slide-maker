# Nari Slide Maker

Free tarot slideshow maker in the Nari style, by [FlashQuest](https://apps.apple.com/us/app/flashquest-flashcards-game/id6760952587).

Paste a slide script (or edit the fields), pick from all 78 built-in Rider-Waite cards, and save 1080x1350 PNGs ready for a TikTok photo post. Runs entirely in the browser.

Card scans: the 1909 Rider-Waite-Smith deck (public domain in the US), via [metabismuth/tarot-json](https://github.com/metabismuth/tarot-json).
